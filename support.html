LOMO Route Studio Support

LOMO Route Studio helps you turn selected iPhone photos into a short route-story video using on-device processing.

Support topics

  • Photo library permission issues
  • GPS-tagged photo availability
  • Route-story generation problems
  • Save to Photos issues
  • LOMO Pro purchase or restore issues
  • Sharing to other apps from the render result screen

Before contacting support

  • Update to the latest build
  • Make sure the selected photos include GPS metadata when possible
  • Confirm the app has photo library access
  • Try creating a shorter route with fewer photos if the device is under heavy load
  • For LOMO Pro: confirm you are signed in to the same Apple ID used for the original purchase, then tap "Restore Purchases" in Settings

LOMO Route Studio 지원

LOMO Route Studio는 선택한 iPhone 사진을 디바이스 안에서 짧은 루트 스토리 영상으로 만들어 줍니다.

지원 주제

  • 사진 라이브러리 권한 문제
  • GPS 태그가 있는 사진 가용성
  • 루트 스토리 생성 오류
  • 사진 앱에 저장 시 문제
  • LOMO Pro 구매 또는 복원 문제
  • 렌더 결과 화면에서 다른 앱으로 공유할 때의 문제

문의 전 확인 사항

  • 최신 빌드로 업데이트
  • 선택한 사진에 가능한 경우 GPS 메타데이터가 포함되어 있는지 확인
  • 앱이 사진 라이브러리 접근 권한을 가지고 있는지 확인
  • 디바이스 부하가 클 때는 더 적은 사진으로 짧은 여정을 만들어 보기
  • LOMO Pro의 경우: 최초 구매에 사용한 Apple ID로 로그인되어 있는지 확인한 뒤, 설정의 "구매 복원"을 누르세요
