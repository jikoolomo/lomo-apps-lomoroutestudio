# LOMO Route Studio

LOMO Route Studio is a local-first iPhone app that turns selected GPS-tagged photos into a short vertical route-story video.

This repository holds the public website, App Store support page, and privacy policy for LOMO Route Studio.

- Issues: https://github.com/jikoolomo/lomo-apps-lomoroutestudio/issues

## Product Definition

LOMO Route Studio is not a general video editor. It is an automatic route video generator. The MVP focuses on one polished automatic output: select photos, read their local time and GPS metadata, build a route story, preview it on Earth, render locally, and save the result to Photos.

## Local-First Scope

- No backend
- No account system
- No cloud upload
- No social posting on behalf of the user
- Photo and route processing happen locally on the iPhone
